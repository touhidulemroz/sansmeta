# Security Policy

## Supported Versions

Security fixes are actively applied to the main branch of this repository.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

We take the security and privacy of SansMeta seriously. As a tool built around metadata sanitization and user privacy, transparent and prompt vulnerability resolution is critical.

If you believe you have found a security vulnerability in SansMeta:

1. **Do NOT open a public issue.**
2. Please report vulnerabilities privately via [GitHub Security Advisories](https://github.com/touhidulemroz/watermarks-cleaner-mac/security/advisories/new).
3. If GitHub Private Vulnerability Reporting is unavailable, you can email the maintainer directly with reproduction steps, an impact assessment, and any proof-of-concept.

### What to include
- A clear description of the vulnerability and attack scenario.
- Step-by-step instructions or minimal reproduction scripts.
- The affected component (`web/backend`, `web/frontend`, `app/`, or engine scripts).

### Response timeline
- We will acknowledge receipt of your report within 48 hours.
- A fix or mitigation plan will be provided as quickly as possible.
- Once fixed, a security advisory will be published acknowledging your contribution (unless you request anonymity).
