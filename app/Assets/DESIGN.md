# App identity

The app icon was generated using the built-in image-generation tool and saved as AppIcon.png. The native icon family is generated by scripts/build.sh.

Final prompt:

Use case: logo-brand. Create one premium macOS app icon for Watermarks Cleaner, a private local metadata cleaning utility. Square 1024x1024. A deep midnight teal rounded-square tile, centered with generous transparent outer margins, containing a single elegant folded ivory document ribbon with a small precise mint four-point glint at the upper right, suggesting a clean fresh file. Sculpted satin material, restrained soft depth, crisp silhouette legible at 32 pixels, refined Apple desktop utility aesthetic. Front facing orthographic, balanced proportions. No text, no letters, no watermark, no mockup, no surrounding objects. Actual transparent background outside the rounded tile. Existing app palette is teal; use that palette.

The interface uses adaptive system teal, native material surfaces, rounded typography, and plain-language results. Raw engine reports remain available in a disclosure section. Sidebar navigation separates file and text tasks; original-preservation and local-processing cues stay visible.
