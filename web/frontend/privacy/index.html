Privacy

SansMeta is a free online utility for inspecting and cleaning hidden AI metadata and invisible Unicode characters. This page describes exactly how files and text are handled, so you can decide what to process.

Where processing happens

SansMeta processes files and pasted text on the server, not in your browser. When you upload a file or submit text, the content is sent over the network to the server running the cleaning engine. The site does not describe this as offline, browser-local, or zero-upload processing.

What the service receives

  • Files you choose to inspect or clean.
  • Text you paste into the text tool.
  • Your choice of the “keep non-AI metadata” option.

No account is required, and the service does not ask for a name, email address, or other identifying information.

Upload and text limits

Default limits, which the operator may lower or raise per deployment:

  • Up to 50 files per batch.
  • Up to 256 MB per file.
  • Up to 8 MB of text per paste.

Storage and retention

Uploads and cleaned copies are written to temporary job workspaces on the server's filesystem. They are deleted in any of these cases:

  • after a completed download (the ZIP download removes the job once the response finishes),
  • when you start over or choose “Clear & delete files”,
  • when you start a new batch (the previous job is purged),
  • or when you close or hide the page (a best-effort request).

A short automatic expiry of __RETENTION_MINUTES__ minutes acts as a fallback for browser crashes, connection loss, interrupted downloads, or failed cleanup requests. Retention is configurable by the operator. Files may also disappear sooner — for example, when the hosting service restarts or redeploys, because jobs are held in memory and workspaces are ephemeral by design.

Closing the page sends a best-effort deletion request, but a browser or network interruption may prevent the server from confirming it; the configured fallback covers that case.

Download links

Each job has both a random identifier and a separate random access token. The server requires both for status, download, cancellation, and deletion requests. Anyone with the complete link can still download the file while the job exists, so do not share it. An operator can optionally require an API key for all API routes too. Job identifiers are never interpreted as file paths.

Analytics and consent

The site uses Google Analytics to understand aggregate usage. Analytics runs only after you accept the consent notice; declining means no analytics script is loaded and no events are recorded. You can review or change your choice by clearing this site’s local storage, which shows the notice again.

Only aggregate events are sent: page views, mode switches, uploads and clean completions (with file counts), downloads (by type), and text cleaning (with character counts). Filenames, file contents, pasted text, and download tokens are never sent to analytics.

Third parties

With consent granted, the only third-party request is Google Analytics. No other third-party scripts, ads, or trackers are loaded.

What SansMeta does not do

  • It does not modify your original files — cleaned copies are separate downloads.
  • It does not use your files or text to train models.
  • It does not claim encryption of stored workspaces or certifications.

Changes

This privacy page is updated together with the code, so it always reflects the deployed behavior.
